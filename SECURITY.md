# Security

Keep Codex authentication in its existing local configuration. IdeaProbe does not copy credentials into research artifacts. Keep local overrides and research data out of Git.

Treat collected text as untrusted. Report issues involving command execution, private-address fetching, credential exposure or unsafe file paths through a private channel to the maintainer before publishing sensitive details.

When reporting, include the affected code version and a minimal reproduction using synthetic data. Remove credentials, private prompts and account information from logs.
