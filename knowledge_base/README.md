# Project knowledge

IdeaProbe reads selected Markdown files from `knowledge_base/project/`. Set `project_research.knowledge_directions` to their filename stems. An explicit path cannot escape that directory.

The root `ProjectProfile.md` is the default developer profile when `knowledge_base/project/project_profile.md` is absent.

The existing notes in this directory are inherited reference material. They are preserved for reference and are not automatically injected into project research. To use a note, review it and place a copy under `project/`, then select it in the configuration.

Keep private notes local and review material before publishing it.
